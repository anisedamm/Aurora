# Scope — the *net* regime: mapping conceptual change into the information age

> **Status: DRAFT for review. No code written, nothing committed.** This is a
> scoping document — a map of the design space and a set of *recommended defaults*
> (each marked **[default]**), every one of which is yours to override before we
> build. It extends the framework with a **third regime of attention** so the same
> machinery that read the breath→pump threshold can read the pump→**net** one we
> are living through now.

## 0. The claim being scoped

The framework already models **one** change in a culture's *mode of attention* —
**breath → pump** (holistic conceptual signs giving way to analytic phonetic ones,
c. 800 BCE) — and every tool it owns is a *threshold* tool, not a breath-specific
one: `migrate` (held-whole → dispersed), `proliferation` (segmented → re-cohered),
`arc` (one thread across the threshold), `project`/`remember` (the ghost lag, both
directions).

The bet: **the information age is a third such threshold with the same structure.**
If so, the extension is *additive* — a third regime alongside two — and the existing
tools generalize to it rather than being replaced. Scoping is deciding exactly what
the third regime **is**, and what must stay **invariant**.

## 1. The third regime — name and definition

The series is bodily/mechanical: **breath** (the lung, participatory) → **pump**
(the machine, segmenting) → **net** **[default name]**. The successor's attention is
*networked / associative / recombinant*: meaning is no longer deferred to a *fixed
lexicon* but to a **queryable statistical field** — hyperlink → search →
recommendation → embedding → LLM — and is frequently **authorless**.

| axis | breath | pump | **net** |
|------|--------|------|---------|
| mode of attention | participatory, holistic | analytic, segmenting | **networked, associative** |
| native script | conceptual sign (a weighted field) | phonetic sign (spells a sound) | **recombinant token (sense from neighbours + context)** |
| meaning lives in | the sign itself | a lexicon | **the network / a statistical field** |
| unit | the symbol | the word | **the token / the link** |
| authorship | the culture | the writer | **often none (emergent, recombined)** |
| McGilchrist analogue | right hemisphere | left hemisphere | **neither — a mechanized field (see §3)** |

Alternatives considered: `field` (leans on the embedding reading), `flux`/`stream`
(leans on never-settled, §2), `mesh` (leans on authorless many-to-many topology).
**Recommendation: `net`** — one syllable, matches the breath/pump cadence, names
the mechanism honestly. Easy to swap; it is a string constant (`regime.NET`).

## 2. Direction of the threshold — the *inverted* discipline

This is the single most consequential decision, because it changes what **L3**
measures.

The breath/pump tools assume **hindsight**: we read *across a completed crossing*,
with the whole record in hand. The net crossing is **happening now — we are inside
the ghost lag, not looking back across it.** That inverts the cardinal error:

| | breath / pump (hindsight) | **net (lived)** |
|---|---|---|
| cardinal error | **anachronism** / **phonetic projection** — projecting the *present onto the past* | **pump projection** — reading the *emerging* mode in the *departing* mode's terms; **and** mistaking a *transient* usage for a *settled* sense |
| L1 attestation | scarce, precious (few cited usages survive) | **superabundant** — the whole internet is cited usage (the framework's weakest layer becomes its strongest) |
| L3 gap | drift of *our* reading from the usage's own time | drift of a *still-being-negotiated* sense toward a premature fixity |

**Recommendation [default]:** keep L3's gap-machinery unchanged, but add an explicit
**`provisional` flag** on net-regime senses, so the framework **never reports a
live, unsettled sense as fixed**. This is the net-regime analogue of the existing
humility ("a reading is a proxy, not the meaning") — here: "a *contemporary* reading
is a proxy for a sense *not yet settled*." Descriptive, never a gate, as ever.

## 3. What the net regime does to meaning — the structural operation

- **breath** *held meaning whole* (one sign, many values, in proportion).
- **pump** *segmented* it (one word, one sense, deferred to a lexicon).
- **net** **re-aggregates** it: dissolves the discrete lexeme back into a continuous
  field where meaning is "held whole" again — **but mechanically, by correlation,
  not by participation.** A *synthetic breath* — a partial **rhyme** with the breath
  regime, achieved by pump means (computation).

This is the richest reading the architecture enables, and the framework already owns
the exact instrument for it: `remember` / `confluence` distinguish a **faithful
return** from "a projection in disguise." So the net regime's rhyme-with-breath
should be **measured, not asserted**.

Options:
- **(A) [default] Third pole that rhymes with breath — and make the rhyme
  measurable.** Model `net` as a genuine third regime whose re-aggregation
  *partially echoes* breath's holism, and use `remember`/`confluence`-style
  resonance to ask, case by case, whether a given net sign is a *genuine* return to
  a whole-held value or a *counterfeit* (the form of holism without the
  participation). Most honest; most generative; refuses to pre-decide.
- (B) Counterfeit return ("synthetic breath" as thesis). Sharper, but bakes a
  verdict into the map the framework usually refuses to pre-decide. Rejected as
  default for that reason; available as a *reading* the tools can surface.
- (C) Pure third pole, no breath rhyme. Safest, but discards the richest reading.

## 4. The seeds — the *labrys* and *revolution* of this regime

Mirror the existing two seed slots:

- **The conceptual sign** (net's *labrys*) — **`meme`** (Dawkins 1976 → net-native
  unit of recombinant culture), or the **emoji** (a literal return of *ideographic,
  weighted-field* signs inside a phonetic-script culture). A net sign that holds a
  weighted field and recombines — the breath apparatus (`weigh`, `read`-as-resonance)
  applies almost directly.
- **The live inversion** (net's *revolution*) — **`viral`** **[default flagship]**:
  biology (~1898, *virus* as contagion) → culture (rapid, self-replicating spread,
  now often *valued*). A clean, datable sense-inversion of a pump-era word, exactly
  the `trace`/`drift` pattern, freshly attested.
  Alternatives: `friend` (noun→verb, relationship→network-edge), `cloud`
  (sky→placeless utility — "meaning lives in the network" made vivid), `stream`,
  `feed`, `troll`, `platform`, `timeline`.

Plus a net-side **untranslatables** set — *doomscroll, ghosting, rizz, cringe,
based* — concepts the networked culture valued enough to name. Lexicalisation as
valuation (§ `lexicon.py`), observable **live**.

**Seed plan [default]:** `viral` as flagship inversion; `meme` as the conceptual
sign; a small net-side lexicon for `untranslatables` and to extend `proliferation`
with a sixth, *net* era.

## 5. The invariant spine — do **not** touch

The extension is **additive**. Everything that makes the record trustworthy stays
exactly as it is:

- **L1 attestation remains the one gate** (and gets *easier*, §2).
- Every other measure stays **descriptive, never a gate**.
- The **authored map carries its provenance** — net entries are proxies that say so.
- The **ledger stays hash-chained**; new records append, breaking nothing.
- **`signal == 1` must still hold** — CI runs it on every push.
- The **breath and pump regimes are unchanged**; `net` sits alongside them.

## 6. Model changes implied (for the build phase — not yet)

A faithful, minimal set, deferred until the scope above is locked:

1. `regime.py` — generalize the hard binary (`VALID_REGIMES = {BREATH, PUMP}`,
   single `NATIVE_SCRIPT`) to an **ordered sequence** `breath → pump → net`, each
   with a ghost lag to its predecessor and its own native script. Keep all existing
   breath/pump behaviour bit-for-bit; `net` is purely additive.
2. `glossary.json` / `lexicon.json` — seed the §4 entries (provenance-carrying,
   `provisional` where live).
3. `migrate` / `arc` / `proliferation` — admit a **third column** so a value can be
   traced breath → pump → **net** on one timeline; add the §3 *rhyme-with-breath*
   resonance as a reading on top of existing `remember`/`confluence`.
4. Tests + `seed.py` re-run + `manifest` refresh; confirm `signal == 1`.
